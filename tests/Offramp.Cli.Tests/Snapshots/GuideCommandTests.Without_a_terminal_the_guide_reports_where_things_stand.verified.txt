  Write offramp.yml

  offramp.yml records the target .NET version, which solution to work on, how changes are verified, and package versions
  you must keep. Every command reads it. On a terminal, init asks a few questions with the detected answers as defaults,
  and it adds Offramp's scratch files to .gitignore.

  Command: offramp init

Run it with offramp guide --run init, or record it with --done or --skip.
